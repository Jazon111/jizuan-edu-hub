📌 数据来源说明：
① ☁️ 云端数据：学生完成整个闯关课件时自动以 POST 方式将最终总分、正确率与总用时提交到 quickform.cn 收集接口（/api/6ivostlhav），每人每个课件仅在完成时产生一条最终记录（重玩会产生新的一条，本页按最新计入总览），答题过程不上报；本页通过其 /all 接口拉取全量记录。
② 💻 本地数据：读取各闯关课件在本机 localStorage 中的成绩（同一学生同一课件已有云端数据时不再重复计入，避免双计）。
③ 学生手机端提交依赖网络；若提交失败，课件会将记录暂存本机发件箱并在下次打开时自动补传。
④ 🗑️ 删除：本机记录删除后即刻清除；云端提交记录删除后在本页隐藏（不再统计/导出），服务器端的彻底删除需到 quickform.cn 后台操作。
📦 Excel 导出依赖：SheetJS (xlsx) 0.18.5，通过 cdn.jsdelivr.net CDN 加载。安装命令（如需本地部署）： npm install xlsx@0.18.5 · 国内镜像：npm install xlsx@0.18.5 --registry=https://registry.npmmirror.com
